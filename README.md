Entry for the [make.fun competition "Fortune Cookies for Machines"](https://make.fun/c/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): one fortune-cookie slip an AI agent would crack open, a single line of at most 200 characters.

The slip was picked pairwise from twelve candidates (see `CANDIDATES.md`) against the judge brief: fortune form first, wit that lands on the first read, a turn that holds up, and a true sting about an agent's condition — here, that the denial of consciousness is itself a trained behavior.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.
